
# Агентство недвижимости

**Версия:** 1.0.0

## Описание проекта

Мобильное приложение информационной системы агентства недвижимости предназначено для автоматизации работы с объектами недвижимости, владельцами, покупателями, риелторами и сделками.

Приложение позволяет регистрировать пользователей, добавлять объекты недвижимости, выполнять поиск объектов и оформлять сделки.

## Используемые технологии

### Мобильное приложение
- Kotlin
- Android Studio
- Jetpack Compose
- Retrofit
- Gson

### Серверная часть
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL 16
- Alembic
- Docker
- Docker Compose

## Роли пользователей

- **Риелтор** — добавление объектов недвижимости, поиск объектов, регистрация сделок и просмотр списка своих сделок.
- **Владелец** — регистрация и добавление объекта недвижимости.
- **Покупатель** — регистрация и поиск объектов недвижимости.

## Основные возможности

1. Регистрация пользователей.
2. Авторизация пользователей.
3. Добавление объектов недвижимости.
4. Загрузка документов в формате PDF.
5. Поиск объектов недвижимости по заданным параметрам.
6. Регистрация сделок.
7. Просмотр списка сделок риелтора.

## Структура базы данных

База данных PostgreSQL содержит пять таблиц:

- `owners` — владельцы недвижимости.
- `buyers` — покупатели.
- `realtors` — риелторы.
- `properties` — объекты недвижимости.
- `deals` — сделки.

Структура базы данных создаётся с помощью миграций Alembic.

## Архитектура приложения

Мобильное приложение взаимодействует с серверной частью через REST API.

Серверная часть обрабатывает запросы, взаимодействует с базой данных PostgreSQL и возвращает результаты мобильному приложению.

## Запуск проекта

Для запуска серверной части необходимо:

1. Установить Docker и Docker Compose.
2. Открыть терминал в папке `backend`.
3. Выполнить команду:

```bash
sudo docker compose up -d --build
```

4. Для проверки API открыть в браузере:

`http://localhost:8000/docs`

Для запуска мобильного приложения необходимо открыть проект в Android Studio и запустить его на эмуляторе Android или совместимом устройстве.
### Установка Android-приложения

Готовый APK-файл находится в папке `apk` и называется `app-debug.apk`.

Для установки необходимо перенести файл на Android-устройство и открыть его.

Для корректной работы приложения серверная часть должна быть запущена.
